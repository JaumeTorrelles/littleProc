# LittleProc CPU Implementation

A full CPU implementation based on the LittleProc architecture, developed as a class project using Quartus.

![LittleProc Execution Trace](CAPTURA_littleProc_final.png)
*Simulation waveform showing the CPU execution.*

## Schematics

High-quality vector schematics are available in the PDF documentation. These are vector files, ensuring no loss of quality when zoomed:

- [Top Level Architecture (LittleProc)](littleProc.pdf)
- [Processing Unit (UP)](UP.pdf)
- [Control Unit (UC)](UC.pdf)

## Structure

- `Projecte/`: Contains the VHDL/Schematic source files and Quartus project.
- `*.pdf`: Documentation and schematics.

## Usage

This project was built using **Quartus II 9.0sp2 Web Edition**. Open the `Projecte/LittleProc.qpf` file with this version (or compatible newer versions) to load the project.
